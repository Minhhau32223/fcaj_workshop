## Introduction

During the **8-week internship** from **June 22, 2026 to August 15, 2026**, I participated in developing the **Automatic Image Optimization System on AWS** project in the role of **DevOps & Documentation**.

The work focused on researching and deploying infrastructure based on a **Serverless** architecture, building the deployment process using **AWS CDK**, integrating AWS services, completing the monitoring and alerting system, as well as creating technical documentation and deployment guides for the project.

Throughout the internship, tasks were carried out in stages, from researching the system architecture, deploying infrastructure, building APIs, and expanding the Event-driven architecture, to setting up Monitoring, CI/CD, testing, and finalizing documentation before project acceptance.

## Weekly Content

**Week 1:** [Survey project requirements and design the overall architecture](1.1-week1/)

**Week 2:** [Deploy Amazon S3, AWS Lambda, and build the basic Image Processing Pipeline](1.2-week2/)

**Week 3:** [Integrate Amazon DynamoDB and complete the Core Image Optimization Pipeline](1.3-week3/)

**Week 4:** [Deploy Amazon API Gateway and build the Upload API](1.4-week4/)

**Week 5:** [Expand the system with an Event-driven architecture using Amazon EventBridge](1.5-week5/)

**Week 6:** [Set up Monitoring, Alerting, and enhance system security](1.6-week6/)

**Week 7:** [Complete the CI/CD Pipeline, conduct End-to-End testing, and optimize the system](1.7-week7/)

**Week 8:** [Finalize technical documentation, summarize the project, and prepare for the report and demo](1.8-week8/)
